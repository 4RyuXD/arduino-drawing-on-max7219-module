# arduino-drawing-on-max7219-module
Using a Joystick to draw on a MAX7219 module

-Components-

Arduino Mega 2560 Microcontroller

MAX7219 Module

Joystick Module

Male to Female Wires

Breadboard


-Libraries-
LedControl by Eberhard Fahle

-IMPORTANT-

The code uses pin 52 for clk which is available on the arduino mega but is not shown in the Circuit Diagram and pin 11 is used in CS but is not shown in the circuit diagram

Connect the pins according to your microcontroller

SPI BUS Serial Clock (SCK): 52/13
CS: any digital pin or MOSI/POCI pin

adjust the code as well according to your pins
